# 平板／手機使用說明 — 璞石 Render Studio

> 更新：2026-10-09｜對象：Banson、設計主管、設計師

## 1. 結論

不用安裝 App。用 iPad／iPhone 的 Safari（或 Android 的 Chrome）打開 https://pure-render-studio.vercel.app 就能用。

| 裝置 | 適合做的事 | 實測（Chromium 模擬，非實機）|
|---|---|---|
| iPad 橫放 | 完整流程：上傳原圖、框選、下載任務包、匯入結果、驗收核准、360、交付 | 左圖右面板並排，全流程無錯誤 |
| iPad 直放 | 同上，面板改在圖下方 | 全流程無錯誤 |
| 手機 | 看進度、核准／退回、看 360、簡單框選 | 可操作但畫面小，不建議當主力 |

## 2. 第一次登入（每台裝置各一次，30 天有效）

1. 在**要使用的那台裝置**用 Safari 打開網址，輸入 Email，按「寄送登入連結」。
2. 在**同一台裝置**收信、點信中的按鈕。
   - 用「郵件」App 收信：會直接開到 Safari，沒問題。
   - 用 Gmail App／LINE 收信：會開在它們的內建瀏覽器，**登入不會帶到 Safari**。請點右上角「⋯」→「在瀏覽器中開啟」。
3. 原則：**連結在哪個瀏覽器打開，就登入在哪個瀏覽器**。在電腦點連結，iPad 不會跟著登入。

## 3. 加到主畫面（建議，但要關一個開關）

Safari → 分享 → 加入主畫面 → **把「以網頁 App 開啟」（Open as Web App）開關關掉** → 新增。

- 為什麼要關：iOS 26 起，加入主畫面預設會變成獨立的「網頁 App」，它跟 Safari 的登入狀態與資料分開存放；登入信的連結卻會開在 Safari，於是主畫面圖示永遠停在登入頁、也看不到在 Safari 建的專案。
- 關掉後，主畫面圖示只是捷徑，點了在 Safari 開，登入與專案都共用。

## 4. 資料在哪裡（最重要）

- 專案存在**那台裝置的瀏覽器裡**，電腦、iPad、手機**彼此不會自動同步**。
- 換裝置接續：舊裝置「交付」分頁 →「專案備份」下載 `.json` → 用 AirDrop／雲端硬碟傳到新裝置 → 首頁「匯入備份」。
- 新裝置已有同一個專案時，系統會顯示兩邊最後修改時間，確認後以備份覆蓋；備份比裝置上的版本舊時會特別警告。
- **iPad／iPhone 的 Safari 若連續 7 天有在用 Safari、但沒打開這個網站，可能清掉本站資料**（Apple 的追蹤防護規則）。停工超過一週的專案，請先匯出備份。
- 根本解法是伺服器儲存（HANDOFF 待辦 P1），完成後就能多裝置同步。

## 5. 平板上的 ChatGPT 手動流程

1. 版本頁「2 生成」→「下載 ChatGPT 任務包」（ZIP 存到「檔案」App → 點一下即解壓）。
2. 開 ChatGPT App，新對話，依檔名編號上傳圖片，貼上提示詞（工作台「1 指令」→ 編譯結果 →「複製」）。
3. ChatGPT 出圖後長按 →「儲存影像」或分享到「檔案」。
4. 回工作台「匯入 AI 結果」選那張圖；系統自動放大、對位、回貼、篩查水波紋。

## 6. AI 金鑰（每台裝置各設一次）

右上角齒輪「設定」填 OpenAI／Claude 金鑰後，平板上也能直接出圖、讓 Claude 驗收，不必在 ChatGPT App 之間往返。金鑰只存在該裝置，電腦設過的 iPad 不會自動有。詳見 `docs/SETTINGS-GUIDE.md`。

## 7. 已知限制

| 項目 | 說明 |
|---|---|
| 未在 iPad 實機驗證 | 目前是 Chromium 模擬 iPad／iPhone 尺寸與觸控；Safari 細節（下載、檔案挑選）需實機確認一次 |
| 手機畫面小 | 框選精準度有限，正式修圖建議用 iPad 或電腦 |
| Apple Pencil | 走一般觸控事件，可框選與筆刷；未做壓力感應 |
