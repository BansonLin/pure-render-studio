# 設定說明：金鑰、上限、空間與圖號 — 璞石 Render Studio

> 更新：2026-10-10｜對象：Banson（管理者）、設計主管、設計師

## 1. 結論

- 金鑰**由管理者在「設定」頁輸入一次**，加密存在璞石後台；之後所有電腦、平板、同事都直接能用，不必再輸入。
- 只有管理者能改金鑰、模型、上限、空間與圖號預設；設計師只能查看狀態與使用功能。
- 出圖與驗收由**伺服器**代為呼叫 OpenAI／Anthropic，金鑰不會出現在任何人的瀏覽器。

| 功能 | 需要 | 在哪裡用 |
|---|---|---|
| AI 直接出圖 | OpenAI 金鑰 | 版本頁「2 生成」→「OpenAI API」→ 勾同意 →「送出生成」，結果自動匯入、對位、回貼 |
| 看圖驗收建議 | Claude 金鑰 | 版本頁「3 驗收」→「請 Claude 檢查」→ 逐項建議，按「採用」或「把建議填進尚未判定的檢查項」 |
| ChatGPT 手動模式 | 不用金鑰 | 跟以前一樣，隨時可切回 |

## 2. 誰是管理者

- 預設：白名單（`ALLOWED_EMAILS`）的**第一個** Email，目前就是 Banson。
- 要多加管理者：Vercel → Settings → Environment Variables 新增 `ADMIN_EMAILS`，填 Email（逗號分隔）→ Redeploy。

## 3. 金鑰存在哪裡（安全）

| 項目 | 做法 |
|---|---|
| 存放 | Vercel 私有儲存（Blob，名稱 `render-studio-settings`），只有伺服器讀得到 |
| 加密 | AES-256-GCM，加密鑰匙由 `AUTH_SECRET` 衍生；儲存區外流也讀不到金鑰 |
| 顯示 | 任何人（包括管理者）之後都只看到末四碼與「誰、何時設定」 |
| 不會出現在 | 瀏覽器、專案備份、交付包、提示詞、事件紀錄 |
| 注意 | 若更換 `AUTH_SECRET`，舊金鑰無法解密，需在設定頁重新輸入 |

## 4. 取得 OpenAI 金鑰（出圖）

1. 到 https://platform.openai.com 登入公司帳號。
2. **Billing**：儲值或綁卡。
3. **Settings → Limits**：設每月預算上限（例如 US$50）。這是供應商端的硬上限。
4. **API keys → Create new secret key**：名稱填 `render-studio`，複製。
5. 回工作台「設定」貼上 →「測試並儲存到後台」。
6. 若出圖時出現「組織驗證」錯誤：OpenAI 後台 **Settings → Organization → Verify**，完成後再試。

## 5. 取得 Claude 金鑰（驗收）

1. 到 https://console.anthropic.com 登入（用公司 Email 註冊）。
2. **Billing**：儲值。
3. **Limits**：設每月花費上限（例如 US$20）。
4. **API Keys → Create Key**：名稱填 `render-studio`，複製。
5. 回工作台「設定」貼上 →「測試並儲存到後台」→ 模型預設 `Claude Opus 5.5`（看圖最仔細）。

注意：**Claude Pro／Max 訂閱不能用在這裡**。網站要用 API 金鑰，費用另計。

## 6. 全公司每月上限

- 設定頁每個功能各有「全公司每月上限」（10–1000 或不限），由**伺服器**計算，換裝置也算同一本帳。
- 達上限時，出圖或驗收會直接回「已達上限」，不會送到供應商。
- 設定頁下方「本月用量」列出每位使用者用了幾張／幾次。
- 供應商後台的硬上限仍建議設定，雙重保險。

## 7. 空間與圖號預設

- 設定頁最下方「空間與圖號預設」：每列一個空間，可改名稱、填起始圖號、上下移、刪除、新增。
- 新增視角時：
  - 「空間」下拉照這裡的順序列出，選不到可選「其他（自行輸入）」。
  - **圖號留空就自動編**：有起始號的空間從起始號往上找空號（例：客廳 20 → 20、21、22…）；沒起始號的接在專案目前最大號之後。
  - 也可以從圖號欄的下拉建議挑，或自己輸入；重複會提示。
- 系統預設【示意】：玄關 10、客廳 20、餐廳 30、廚房 40、主臥 50、主臥衛浴 60、次臥 70、小孩房 80、書房 90、客衛 100、更衣室 110、陽台 120；其餘不指定。**請改成公司慣用的編號**。

## 8. 畫布上的連線（主圖 → 衍生）

| 看到的 | 意思 |
|---|---|
| 線從 A 連到 B，標示「A→B」 | B 是「衍生視角」，依賴主圖 A |
| 虛線、灰色 | 主圖 A 還沒核准：B 不能送出生成（會被擋下並提示） |
| 實線、綠色 | 主圖 A 已核准：B 開新版本時自動帶入 A 的核准圖當參考 |

實際用法：

1. 同一個空間挑最完整、最重要的一張設為「主圖」（例：客廳正景 33），其他角度設為「衍生」並勾選依賴 33。
2. 先把主圖做到核准。
3. 再做衍生視角：系統自動帶入主圖當參考，並註明兩張共有的物件（沙發、吊燈…），讓 AI 照主圖的造型、材質、數量畫。
4. 主圖之後若改版重新核准，已核准的衍生版本會被標「需重驗」，提醒你回頭確認一致性。
5. 關係設錯：點視角標頭的鉛筆「編輯」，可改名稱、空間、角色、依賴的主圖（圖號不能改）。
