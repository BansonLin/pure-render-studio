# 設定說明：金鑰、上限、空間與圖號 — 璞石 Render Studio

> 更新：2026-10-12｜對象：Banson（管理者）、設計主管、設計師

## 1. 結論

- 金鑰**由管理者在「設定」頁輸入一次**，加密存在璞石後台；之後所有電腦、平板、同事都直接能用，不必再輸入。
- 只有管理者能改金鑰、模型、上限、空間與圖號預設；設計師只能查看狀態與使用功能。
- 出圖與驗收由**伺服器**代為呼叫 OpenAI／Google／Anthropic，金鑰不會出現在任何人的瀏覽器。

| 功能 | 需要 | 在哪裡用 |
|---|---|---|
| AI 直接出圖（寫實度最好） | Google 金鑰 | 版本頁「2 生成」→「Google」→ 勾同意 →「送出生成」，結果自動匯入、對位、回貼 |
| AI 直接出圖 | OpenAI 金鑰 | 版本頁「2 生成」→「OpenAI」→ 勾同意 →「送出生成」 |
| 精簡指令 | Claude 金鑰 | 版本頁「1 指令」→「請 Claude 寫精簡指令」→ 核對中文摘要與警示 → 出圖 |
| 看圖驗收建議 | Claude 金鑰 | 版本頁「3 驗收」→「請 Claude 檢查」→ 逐項建議，按「採用」或「把建議填進尚未判定的檢查項」 |
| 手動任務包 | 不用金鑰 | 下載任務包，在 ChatGPT 或 Luma（Modify Image → Nano Banana Pro）完成後匯回 |

## 2. 誰是管理者

- 預設：白名單（`ALLOWED_EMAILS`）的**第一個** Email，目前就是 Banson。
- 要多加管理者：Vercel → Settings → Environment Variables 新增 `ADMIN_EMAILS`，填 Email（逗號分隔）→ Redeploy。

## 3. 金鑰存在哪裡（安全）

| 項目 | 做法 |
|---|---|
| 存放 | Vercel 私有儲存（Blob，名稱 `render-studio-settings`），只有伺服器讀得到 |
| 加密 | AES-256-GCM，加密鑰匙由 `AUTH_SECRET` 衍生；儲存區外流也讀不到金鑰 |
| 顯示 | 任何人（包括管理者）之後都只看到末四碼與「誰、何時設定」 |
| 不會出現在 | 瀏覽器、專案備份、交付包、提示詞、事件紀錄 |
| 注意 | 若更換 `AUTH_SECRET`，舊金鑰無法解密，需在設定頁重新輸入 |

## 4. 取得 OpenAI 金鑰（出圖）

1. 到 https://platform.openai.com 登入公司帳號。
2. **Billing**：儲值或綁卡。
3. **Settings → Limits**：設每月預算上限（例如 US$50）。這是供應商端的硬上限。
4. **API keys → Create new secret key**：名稱填 `render-studio`，複製。
5. 回工作台「設定」貼上 →「測試並儲存到後台」。
6. 若出圖時出現「組織驗證」錯誤：OpenAI 後台 **Settings → Organization → Verify**，完成後再試。

## 4-1. 取得 Google 金鑰（出圖，Nano Banana Pro）

Luma 調查中效果最好的圖，就是 Luma 裡選用的 Google Nano Banana Pro；工作台直接接 Google，不必經過 Luma。

1. 用公司 Google 帳號到 https://aistudio.google.com ，點「Get API key」→「Create API key」（會順便建立一個 Google Cloud 專案）。
2. **一定要綁定付費帳戶**：AI Studio 的 Billing／Google Cloud 主控台 → 帳單，綁信用卡，讓這個專案變成付費層。免費層送出的圖可能被 Google 拿去改進模型，付費層不會（需專業人士最終確認是否符合建商合約）。
3. Google Cloud 主控台 → 帳單 →「預算與快訊」設每月預算（例如 US$50）。注意：Google 的預算**只寄提醒、不會自動停用**，硬上限靠工作台的「全公司每月上限」。
4. 複製金鑰（`AIza` 開頭）→ 回工作台「設定」的 Google 卡片貼上 →「測試並儲存到後台」→ 模型預設 Nano Banana Pro、解析度 2K。
5. 第一次出圖若出現 400 錯誤，把畫面上的完整錯誤訊息截圖給開發（Google 近期有調整 API 格式；400 不計費）。

## 5. 取得 Claude 金鑰（驗收、寫精簡指令）

1. 到 https://console.anthropic.com 登入（用公司 Email 註冊）。
2. **Billing**：儲值。
3. **Limits**：設每月花費上限（例如 US$20）。
4. **API Keys → Create Key**：名稱填 `render-studio`，複製。
5. 回工作台「設定」貼上 →「測試並儲存到後台」→ 模型預設 `Claude Opus 5.5`（看圖最仔細）。

注意：**Claude Pro／Max 訂閱不能用在這裡**。網站要用 API 金鑰，費用另計。

## 6. 全公司每月上限

- 設定頁每個功能各有「全公司每月上限」（10–1000 或不限），由**伺服器**計算，換裝置也算同一本帳。
- 達上限時，出圖或驗收會直接回「已達上限」，不會送到供應商。
- 設定頁下方「本月用量」列出每位使用者用了幾張／幾次。
- 供應商後台的硬上限仍建議設定，雙重保險。

## 7. 空間與圖號預設

- 設定頁最下方「空間與圖號預設」：每列一個空間，可改名稱、填起始圖號、上下移、刪除、新增。
- 新增視角時：
  - 「空間」下拉照這裡的順序列出，選不到可選「其他（自行輸入）」。
  - **圖號留空就自動編**：有起始號的空間從起始號往上找空號（例：客廳 20 → 20、21、22…）；沒起始號的接在專案目前最大號之後。
  - 也可以從圖號欄的下拉建議挑，或自己輸入；重複會提示。
- 系統預設【示意】：玄關 10、客廳 20、餐廳 30、廚房 40、主臥 50、主臥衛浴 60、次臥 70、小孩房 80、書房 90、客衛 100、更衣室 110、陽台 120；其餘不指定。**請改成公司慣用的編號**。

## 8. 出圖效果：整張變寫實 vs 只改一塊

| 想要 | 做法 | 結果 |
|---|---|---|
| 整張提升寫實感（光影、材質、攝影質感），設計不變 | 「1 指令」**不框選** → 按「一鍵：整體渲染增強」→「2 生成」送出 | 整張採用 AI 結果，原生 2048 寬輸出 |
| 只改某個地方（換沙發色、修牆面） | 框選修改區 → 寫區域說明 → 送出 | 框外自動還原成 3D 原圖，只有框內是 AI 的 |

- **兩者不要混用**：有框選時，增強效果只會留在框內，框外仍是原本的 3D 算圖。
- **建議先按「請 Claude 寫精簡指令」**：Claude 看這張圖，點名畫面裡要保留的門窗、櫃體、家具，只列 1–4 項變更。Luma 實測這種短指令在只修一輪時結構保持最好。寫完會顯示中文摘要與警示，核對後再出圖；之後改了需求、框選或參考圖，系統會提醒重寫。
- **不要寫「所有窗簾統一」「整組櫃體換色」這類泛指**：Luma 實測會憑空加窗、白櫃變木紋、吊燈掛錯位置。請逐項點名，或分視角各自處理。
- 增強積木也可以在「提示詞積木」裡個別開關（寫實光影、材質質感、建築攝影成像）。
- 這是一次性的 AI 影像編輯，不是重新算圖；遇到結構走樣、物件變多，用「3 驗收」退回再出一張，不要在同一張上連續重生成（會累積水波紋）。

## 9. 畫布上的連線（主圖 → 衍生）

| 看到的 | 意思 |
|---|---|
| 線從 A 連到 B，標示「A→B」 | B 是「衍生視角」，依賴主圖 A |
| 虛線、灰色 | 主圖 A 還沒核准：B 不能送出生成（會被擋下並提示） |
| 實線、綠色 | 主圖 A 已核准：B 開新版本時自動帶入 A 的核准圖當參考 |

實際用法：

1. 同一個空間挑最完整、最重要的一張設為「主圖」（例：客廳正景 33），其他角度設為「衍生」並勾選依賴 33。
2. 先把主圖做到核准。
3. 再做衍生視角：系統自動帶入主圖當參考，並註明兩張共有的物件（沙發、吊燈…），讓 AI 照主圖的造型、材質、數量畫。
4. 主圖之後若改版重新核准，已核准的衍生版本會被標「需重驗」，提醒你回頭確認一致性。
5. 關係設錯：點視角標頭的鉛筆「編輯」，可改名稱、空間、角色、依賴的主圖（圖號不能改）。

## 10. 常見錯誤

| 畫面訊息 | 原因 | 處理 |
|---|---|---|
| OpenAI／Claude 金鑰無效 | 金鑰貼錯或已撤銷 | 到供應商後台重新產生，再貼一次 |
| 金鑰測試成功，但存到後台失敗：… | 後台儲存區暫時寫不進去 | 隔幾秒再按一次；仍失敗把整段訊息截圖給開發 |
| 本月全公司已用…達到上限 | 全公司月上限到了 | 管理者在本頁調高上限 |
| 組織驗證（OpenAI） | OpenAI 帳號未完成驗證 | OpenAI 後台 Settings → Organization → Verify |
| Google 金鑰無效 | 金鑰貼錯或專案未啟用 Gemini API | 回 AI Studio 確認金鑰，再貼一次 |
| Google 額度不足 | 專案沒綁付費帳戶或超過配額 | 依 4-1 第 2 步綁定付費帳戶 |
| Google 沒有產生圖片（原因：…） | Google 安全機制擋下 | 改寫需求或換模型再試；這次不計入月用量 |
